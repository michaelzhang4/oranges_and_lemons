# 🍊 Oranges and Lemons 🍋
*A Market Making Game Based on Expected Value of Fruit*

## Overview
Two teams are throwing oranges/lemons into a basket for 15 minutes and you are making trades on the expected number of oranges/lemons that land in the basket at the end of the game. Try to think logically about the decisions you make rather than focusing on the pnl at the end of the game.

You can get an idea of the expected value range by looking at the standard deviation and averages of each team before the game starts.

Created with Pyside6 and matplotlib libraries
